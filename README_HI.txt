दुग्ध समिति बोनस Android ऐप प्रोजेक्ट

महत्वपूर्ण:
यह Android Studio प्रोजेक्ट का सोर्स है, तैयार APK नहीं। इस वातावरण में Android SDK/Gradle build उपलब्ध न होने के कारण APK को यहाँ compile नहीं किया जा सकता।

APK बनाने के चरण:
1. Android Studio कंप्यूटर पर इंस्टॉल करें।
2. इस ZIP को extract करें।
3. Android Studio में "Open" चुनकर DugdhSamitiAndroid फ़ोल्डर खोलें।
4. Gradle sync पूरा होने दें (इंटरनेट आवश्यक हो सकता है)।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
6. APK आम तौर पर app/build/outputs/apk/debug/app-debug.apk में बनेगा।

ऐप में HTML कैलकुलेटर स्थानीय रूप से चलता है। इंटरनेट की जरूरत नहीं है।
सूची का डेटा ऐप की WebView local storage में रहता है। ऐप डेटा साफ करने या ऐप हटाने पर यह मिट सकता है।
